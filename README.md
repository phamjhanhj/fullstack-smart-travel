# fullstack-smart-travel

This repository contains both the backend and frontend components of the Smart Travel application.

## Project Structure
- [backend/](file:///d:/DATN/backend) - Python Backend application.
- [frontend/](file:///d:/DATN/frontend) - Angular Frontend web application.

## Chạy frontend và backend cùng lúc

Từ thư mục gốc dự án:

```powershell
.\dev.cmd
```

Sau khi khởi động:

- Frontend: http://localhost:4200
- Backend: http://localhost:8000
- Swagger: http://localhost:8000/docs

Nhấn `Ctrl+C` để dừng cả hai tiến trình.
